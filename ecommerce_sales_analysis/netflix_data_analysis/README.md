# Netflix Data Analysis

## 📌 About the Project

This project focuses on analyzing the **Netflix dataset** using Python and exploring different aspects of Netflix's content library.

The analysis is performed using **Pandas, NumPy, Matplotlib, and Seaborn** to clean, explore, analyze, and visualize the data.

## 🎯 Objectives

* Explore the Netflix dataset
* Clean and prepare the data for analysis
* Analyze movies and TV shows available on Netflix
* Identify trends in Netflix content
* Analyze content based on countries, genres, ratings, and release years
* Create visualizations to understand the data
* Extract meaningful insights from the dataset

## 🛠️ Tools & Technologies

* Python
* NumPy
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook


## 📊 Analysis

The project explores different questions related to Netflix content, including:

* How many movies and TV shows are available?
* How has Netflix content changed over the years?
* Which countries produce the most content?
* What are the most common genres?
* What are the most common ratings?
* How does Netflix's content vary across different years?
* What are some of the most recent and popular content trends?
