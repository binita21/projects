# Ecommerce Sales Analysis

## Project Overview
This project analyzes ecommerce sales data to understand revenue,
product performance, regional sales, customer behavior, and delivery
performance.

## Dataset
The dataset is stored in `ecommerce_sales.csv`.

It includes order dates, customer IDs, product categories, regions,
quantities, prices, discounts, payment methods, delivery days,
customer ratings, and revenue.

## Project Notebooks

- `ecommerce_sales_analysis.ipynb` — data exploration, analysis, and insights.
- `ecommerce_sales_visualization.ipynb` — sales KPIs and visualizations.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL (for related analysis and practice)

## Key Questions

- Which product categories generate the most revenue?
- Which regions perform best?
- How do sales change over time?
- Which customers contribute the most revenue?
- Is there a relationship between discounts and revenue?
- How do delivery times and customer ratings vary?

## How to Run

1. Download or clone this repository.
2. Install Python and Jupyter Notebook.
3. Install the required libraries: `pandas`, `numpy`, `matplotlib`, and `seaborn`.
4. Open the notebooks in Jupyter.
5. Run the cells in order.

## Conclusion

The project uses exploratory data analysis and visualizations to identify
sales patterns and generate insights that can support business decisions.
